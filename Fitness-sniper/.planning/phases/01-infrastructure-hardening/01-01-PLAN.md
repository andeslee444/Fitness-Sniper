**In `web/src/lib/cognito.ts`:**

1. Add a new exported `refreshSession` function after the existing `getSession()` function. This function:
   - Takes `refreshToken: string` and `email: string` as parameters
   - Returns `Promise<{ accessToken: string; idToken: string } | null>`
   - Calls `InitiateAuthCommand` with `AuthFlow: 'REFRESH_TOKEN_AUTH'`, `ClientId: CLIENT_ID`, and `AuthParameters: { REFRESH_TOKEN: refreshToken }` plus SECRET_HASH if `computeSecretHash(email)` returns a value
   - Returns the new `AccessToken` and `IdToken` from `AuthenticationResult`, or `null` if missing
   - Catches all errors (expired/invalid refresh token) and returns `null` — logs the error with `console.error('[cognito] Refresh failed:', err)`
   - IMPORTANT: Does NOT return a new refresh token — `REFRESH_TOKEN_AUTH` only returns access + ID tokens

2. Do NOT modify `getSession()` — it remains unchanged. Cookie mutation cannot happen inside `getSession()` because it runs in a read-only server context. The client-side 401 interceptor (Phase 2) will call `/api/auth/refresh` separately.

3. Do NOT export `computeSecretHash` or `client` — `refreshSession` encapsulates the usage internally.

**Create `web/src/app/api/auth/refresh/route.ts`:**

1. Create the directory `web/src/app/api/auth/refresh/` if it doesn't exist.

2. Create a `POST` route handler that:
   - Reads `cognito_refresh_token` and `cognito_id_token` from httpOnly cookies via `await cookies()`
   - Returns `{ error: 'No refresh token' }` with status 401 if either cookie is missing
   - Decodes the email from the `cognito_id_token` JWT payload: `JSON.parse(Buffer.from(idToken.split('.')[1], 'base64url').toString()).email` — no network call needed
   - Calls `refreshSession(refreshToken, email)` from `@/lib/cognito`
   - If `refreshSession` returns null, returns `{ error: 'Session expired' }` with status 401
   - On success, creates the response with `NextResponse.json({ success: true })` and sets cookies:
     - `cognito_access_token` = new access token
     - `cognito_id_token` = new ID token
     - Cookie options: `{ httpOnly: true, secure: process.env.NODE_ENV === 'production', sameSite: 'strict', path: '/', maxAge: 60 * 60 * 24 * 30 }`
   - IMPORTANT: Does NOT update `cognito_refresh_token` — `REFRESH_TOKEN_AUTH` does not return a new one
   - Wraps everything in try/catch: on error, logs `console.error('[auth/refresh] Error:', err)` and returns `{ error: 'Session expired' }` with status 401

Import only: `NextResponse` from `next/server`, `cookies` from `next/headers`, `refreshSession` from `@/lib/cognito`.
