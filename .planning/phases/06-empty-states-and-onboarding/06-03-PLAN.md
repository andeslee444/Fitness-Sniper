With:
```typescript
function goToDashboard() {
  // Set dismissal cookie so dashboard layout doesn't redirect back to /onboarding.
  // 30-day expiry. Path=/ so it's readable from any route.
  document.cookie = 'onboarding_dismissed=1; path=/; max-age=2592000; SameSite=Lax';
  router.push('/dashboard');
}
```

This covers both exit paths:

After the existing `isNewUser` computation (line 28), add a cookie check BEFORE the redirect:

```typescript
const isNewUser = !credRows[0]?.exists && !targetRows[0]?.exists;
if (isNewUser) {
  const cookieStore = await cookies();
  const dismissed = cookieStore.get('onboarding_dismissed');
  if (!dismissed) {
    redirect('/onboarding');
  }
}
```

This replaces the current `if (isNewUser) redirect('/onboarding');` one-liner.

The cookie acts as an escape hatch: users who explicitly dismiss onboarding can reach the dashboard even with no data. Users who have never seen onboarding (no cookie, no data) still get redirected.

Do NOT remove the `isNewUser` DB queries — they are still needed. The cookie is only checked when `isNewUser` is true. If the user later adds credentials or targets, `isNewUser` becomes false and the cookie is irrelevant.
