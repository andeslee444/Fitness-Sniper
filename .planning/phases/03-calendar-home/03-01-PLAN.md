- Day header: show abbreviated weekday name and day number, with emerald coloring when isToday.
- Apply heatmap class to the column container based on deduplicated event count.
- Minimum height: `min-h-24`.
- Map deduplicated events to `CalendarEventPill` components, keyed by `event.id`.
