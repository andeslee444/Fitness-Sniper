**1. Add per-studio success rate query to `web/src/app/api/dashboard/stats/route.ts`:**

Add a fourth query to the existing `Promise.all` array:
```typescript
query<{ studio_slug: string; booked: string; total: string }>(
  `SELECT
     studio_slug,
     COUNT(*) FILTER (WHERE status = 'booked') AS booked,
     COUNT(*) AS total
   FROM booking_history
   WHERE user_id = $1
     AND created_at >= NOW() - INTERVAL '30 days'
   GROUP BY studio_slug
   ORDER BY total DESC`,
  [user.sub],
)
```

Destructure the fourth result and add it to the response:
```typescript
const [targetsRes, jobsRes, historyRes, studioStatsRes] = await Promise.all([...]);

return NextResponse.json({
  targets: targetsRes.rows,
  activeJobs: jobsRes.rows,
  recentHistory: historyRes.rows,
  studioStats: studioStatsRes.rows,
});
```

Note: `COUNT(*)` returns `string` in `pg` library (bigint). The component will parseInt.
